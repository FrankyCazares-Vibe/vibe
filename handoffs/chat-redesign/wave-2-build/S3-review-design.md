### S3-DESIGN-1 — MEDIUM — `Your pick` and the picked count fall under 4.5:1 in Light on the result bar
- Where: `src/components/mobile/messages/cards/PollCardView.tsx:111` (`Your pick`, 10.5px/700, `t.coralText`) and `:120` (the picked option's count, 13px/800, `t.coralText`).
- What: both sit ON the picked option's bar (`t.pickedOption.bar` = `rgba(255,92,53,0.16)` over `#FFFFFF` → `#FFE5DF`). `#C8401E` on `#FFE5DF` = **4.16:1** (< 4.5:1, contract 11.0). `Your pick` is on the bar whenever the share is above ~30%; the count whenever the bar reaches the right edge (a 100% option). Night is fine (`#FF8A66` on the .24 bar over `#161515` = 5.61:1).
- Fix: use `t.coralMark` for both spans (identical `#FF8A66` in Night; `#B5381A` in Light = **4.94:1** on the bar) — the same move S1 made for the `Going` word on a tinted surface (`S1-contrast.md`, 11.0 "coral mark on a tinted surface").

### S3-DESIGN-2 — MEDIUM — the sheets carry no `aria-modal="true"`
- Where: `src/components/mobile/messages/compose/CardSheet.tsx:157` (`<Drawer.Content …>`).
- What: 11.0 pins `role="dialog" aria-modal="true" aria-labelledby` on every sheet. vaul's `Drawer.Content` is Radix `DialogContent`: it sets `role="dialog"` and `aria-labelledby` (from `Drawer.Title`), but Radix never writes `aria-modal` (`grep -c aria-modal node_modules/@radix-ui/react-dialog/dist/index.mjs` → 0; it uses `hideOthers` instead). The old `ComposeOverlay.tsx:119` sets the attribute by hand. (S2's `RsvpSheet.tsx:69` has the same gap; S2-review-design.md:220 assumed vaul supplied it — it does not.)
- Fix: add `aria-modal="true"` to the `<Drawer.Content>` props (Radix forwards it).

### S3-DESIGN-3 — MEDIUM — the Event band's club name can run into the coral end of the gradient (< 4.5:1)
- Where: `src/components/mobile/messages/cards/EventCardView.tsx:88` (the name span: 14px/700 `#FAF7F2`, `minWidth: 0`, ellipsis at the band's full width).

### S3-DESIGN-5 — LOW — an unchanged announcement is not re-read
