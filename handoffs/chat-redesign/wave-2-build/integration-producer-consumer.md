### INT-PRODUCER-CONSUMER-2 — MEDIUM — a card's long-press picker: the picked emoji is dropped, Reply is absent, `reactions` never drawn

- **fix** (amend 11.8, additive): `CardBubbleProps` gains `onToggleReaction?: (emoji: string) => void; onReply?: () => void`. In `CardBubble`: `onPick={(emoji) => { setPickerOpen(false); onToggleReaction?.(emoji); }}` and `onReply={onReply && !temp ? () => { setPickerOpen(false); onReply(); } : undefined}`; draw `message.reactions` under the card the way `MessageBubble` draws its chips (or record "no chips on cards" as an open point). `RoomThread.tsx:354` passes `onToggleReaction={(emoji) => void toggleReaction(m, emoji)}` and `onReply={canReply ?
