# Re-sorted: the 70 controls the inventory called broken

**September 10, 2026.** The first sweep marked every non-responding element as a dead control. That was wrong: Vibe is a social network, and counts, badges and status pills are product, not bugs. Franky caught it. This is the corrected classification.

> **Status: final.** Classified in one pass, then challenged in both directions after a first single-pass challenge stalled.
> - **Working displays:** a challenger re-read all 18 against the code, looking for any that were secretly a broken action button. It found none.
> - **Real bugs:** a second challenger re-read every bug looking for any that were actually displays. All 13 unfixed bugs held. It moved the three "looks clickable" items to working displays, because in the code they are already styled as inert — including the eye icon on a post. One further bug turned out moot: it only fires for a user with no handle, and handles are required.

## The correction, in one line

Of the 70 flagged, **only 15 are real bugs**, and 3 of those are already fixed. 21 are displays working exactly as intended, 30 are entry points for features not built yet (build them or leave them, never delete), and 4 were already wrong.
