Adversarial pass over `handoffs/wave-plan-pwa/research/web-nextjs-sw.md`. The research file was not edited.
Method: primary sources only (nextjs.org, installed `node_modules/next` 16.3.4, vercel/next.js GitHub API, serwist/serwist
source + npm, GoogleChrome GitHub, MDN + mdn/browser-compat-data, W3C specs, web.dev, developer.chrome.com, webkit.org,
vercel.com docs, live `curl -I` on www.connectvibe.app).

**Tally: 39 claims checked. 32 CONFIRMED, 7 CORRECTED, plus 8 open items listed as UNVERIFIED.**

#13 (Serwist is even less safe than stated), #18 (both registrars must pass identical options), #35 (push handler must tolerate non-JSON data).
