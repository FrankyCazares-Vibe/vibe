# Vibe brand kit

This is the mood board. Open `index.html` in a browser to flip through it.

The live HTML Otto mockups still live in `otto_mockups/` (local, gitignored).
This folder is the **stills + mark** you send people who need to feel the product
without running the app.

## Folders

| Folder | What goes here |
|---|---|
| `vibe/` | The mark, tab icon, and product surfaces (landing, login) |
| `otto/` | Otto's visual language — states, corner orb, panel, onboarding |
| `more/` | Drop extra refs here: photos, competitor stills, one-off posters |

## Tokens

From `DOCS/DESIGN_SYSTEM.md`. Don't invent new ones without updating both.

| Token | Hex | Role |
|---|---|---|
| Cream | `#FAF7F2` | Page background. Calm chrome. |
| Charcoal | `#1C1C1E` | Text, dark Otto surfaces |
| Accent | `#FF5C35` | Signature orange. The period in `vibe.` Coral = action. |
| Purple | `#7C5CFC` | Otto intelligence. Never use as a primary brand fill. |
| Lavender | `#C8B8FF` | Otto secondary |
| Muted | `#8A8580` | Secondary text |

**Fonts:** Fraunces (display / `vibe.` wordmark) + DM Sans (UI / body).

**Voice of the chrome:** serious tool first, personality in the words and in Otto.
No decorative emoji in UI chrome.

## The mark

`vibe/logo.png` — V in an incomplete orange orbit, orange node at 4 o'clock.
White rounded square. That's the app icon (`src/app/icon.png`, `apple-icon.png`).

Wordmark in product UI is still lowercase **vibe.** in Fraunces, charcoal, with
the orange period. Don't replace that with the V-mark on in-app headers.

## How to add more

Drop files into the matching folder, then add a card in `index.html`.
Keep stills landscape-ish. Don't commit random 4K dumps — crop to the frame.
